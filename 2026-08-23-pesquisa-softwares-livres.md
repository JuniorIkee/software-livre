# Semana 1

Durante a primeira semana da disciplina, pesquisei projetos de software livre que poderiam me interessar para acompanhar e contribuir ao longo do semestre. Como não tenho experiência contribuindo em projetos open source, pesquisei projetos que não fossem muito complexos logo de início.

Meu receio é acabar levando muito tempo ou simplesmente não entendendo a estrutura do projeto para conseguir contribuir de alguma forma. Por isso, procurei projetos que tinham os requisitos da disciplina (atividade recente e uma comunidade ativa), não muito complexos e que eu já conhecesse ou tivesse utilizado em algum momento. Três deles me interessaram: Simple Icons, Pico CSS e Bruno.

O Simple Icons é um projeto de ícones SVG que já utilizei em projetos e trabalhos da faculdade. Achei interessante que existem contribuições como atualização ou adição de ícones. Penso que poderia fazer todo o fluxo de contribuição até mais de uma vez, desde a escolha de uma issue até a criação de PRs para diferentes ícones.

O Pico CSS é um framework CSS mais minimalista. É uma opção para mim que gosto de CSS, eu poderia criar novos componentes para agregar no projeto e melhorar minhas habilidades no frontend.

Já o Bruno é uma ferramenta de desenvolvimento e teste de APIs que já utilizei durante meu trabalho. Houve um período, que por risco de vazarem dados ao adicionar a conta pessoal, o Postman foi bloqueado e acabei utilizando o Bruno como alternativa para continuar com os testes de requisições nas APIs.

Vi que é uma boa ferramenta, mas com vários ajustes e melhorias que poderiam ser feitos (não seria minha primeira opção para uso). Seria interessante contribuir com essa ferramenta e tentar torná-la mais interessante para os usuários finais, incluindo eu. Ao mesmo tempo, entre os três projetos pesquisados, acredito que o Bruno seria o mais complexo para começar.

Ainda não defini o projeto nesta primeira semana. O próximo passo será analisar com mais atenção os repositórios, as regras de contribuição e as issues abertas de cada um deles. Percebi durante as pesquisas que a comunidade pode ser um fator decisivo, por isso quero entender melhor como funciona a comunidade de cada projeto também.
